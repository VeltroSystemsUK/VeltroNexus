# Learn Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `learn.stratanexus.co.uk` as Strata’s public training hub — Start here path, library, HTML5 player for SuperGrok MP4s, “this helped,” librarian bot, publish-from-Nexus after Editorial-style gates — and point `sme_open` at it.

**Architecture:** Same Express app, two doors. `Host: learn.stratanexus.co.uk` serves a public React tree and `/api/learn/*` (live snapshots only). Nexus stays on `leads.stratanexus.co.uk`. Articles snapshot from Editorial; videos draft in `learn_videos` then snapshot to `learn_pieces`. SuperGrok files are copied into `uploads/learn/videos/` and played locally — never hot-linked from `assets.grok.com`. Librarian retrieves live pieces and `houseAsk`s; eligibility questions never hit the model.

**Tech Stack:** TypeScript, Zod, Vitest, Express, React, wouter, TanStack Query, existing `houseAskWithEngine`, lucide-react, multer (already in package.json). No new npm packages. No TipTap, no stream vendor, no forum.

**Spec:** `docs/superpowers/specs/2026-09-03-learn-hub-design.md`

## Global Constraints

- Open house: no Learn login, no email gate
- No comments, chat, forum, members’ room, or bot-run quiz
- `autoPublish` hard-false on every video draft write
- Packager not lender; no invented rates; no consumer-credit *offers*
- The word **payday** is allowed on Learn when the piece is *warning against* commercial payday-style debt (corpus lesson 1). Still block `we lend`, APR, guaranteed, consumer loan
- Publish is a Director action after marketing approve **and** compliance cleared
- Edit of live copy unpublishes until republish
- Public APIs 404 unless `isLearnHost(Host)`
- Do not call live Anthropic, xAI, or Firecrawl in CI
- Do not change Craft week, Media Gallery, or cadence mails other than `sme_open`
- Windows PowerShell: `git commit -m "message"` (no bash heredocs)
- No new dependencies

import { Router } from "express";
import { storage } from "../storage";
import { buildLearnHome, helpedCookieValue, isLearnHost, parseHelpedCookie, toLearnPublic } from "@shared/learn";

const router = Router();

function requireLearnHost(req, res, next) {
  const host = req.get("x-forwarded-host") || req.get("host");
  if (!isLearnHost(host)) return res.status(404).json({ error: "not found" });
  next();
}

router.use("/learn", requireLearnHost);
router.get("/learn/home", async (_req, res) => {
  const live = await storage.listLiveLearnPieces();
  res.json(buildLearnHome(live));
});
router.get("/learn/library", async (_req, res) => {
  const { library } = buildLearnHome(await storage.listLiveLearnPieces());
  res.json({ library });
});
router.get("/learn/piece/:kind/:slug", async (req, res) => {
  const kind = req.params.kind === "article" ? "article" : req.params.kind === "video" ? "video" : null;
  if (!kind) return res.status(404).json({ error: "not found" });
  const row = await storage.getLiveLearnPieceBySlug(kind, req.params.slug);
  if (!row) return res.status(404).json({ error: "not found" });
  res.json(toLearnPublic(row));
});
router.post("/learn/piece/:id/helped", async (req, res) => {
  const id = parseInt(String(req.params.id), 10);
  const already = parseHelpedCookie(req.get("cookie")?.split("learn_helped=").pop()?.split(";")[0]);
  const row = await storage.getLearnPiece(id);
  if (!row || !row.live) return res.status(404).json({ error: "not found" });
  let thisHelped = row.thisHelped || 0;
  let ids = already;
  if (!already.includes(id)) {
    const next = await storage.incrementLearnHelped(id);
    thisHelped = next?.thisHelped ?? thisHelped + 1;
    ids = [...already, id];
  }
  res.setHeader("Set-Cookie", `learn_helped=${helpedCookieValue(ids)}; Path=/; SameSite=Lax; Max-Age=31536000`);
  res.json({ thisHelped });
});
