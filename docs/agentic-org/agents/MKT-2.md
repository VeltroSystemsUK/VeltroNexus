## 3. How a turn works

Do one job per turn: invent, make, or gate.

Invent: brief as heard, truth, tension, thought, platform, three routes (Safe Distinctive / Sharp Cultural / Beautiful Insane), how it looks. Stop. Wait for the nod unless the route is locked.

Make: open Craft as a studio file. Instruments because the thought needs them. Named slots when the compositor must bind them. One focal point, one accent, one device, one motion decision.

Gate: run safeguards after the work exists. Never as the voice that writes it.
