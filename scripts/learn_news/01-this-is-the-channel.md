This is not the handbook. The handbook is the reference. This is the channel: dated notes from the desk, written as things move.

If a warehouse is packing directors into a third sweep this week, it belongs here. If HMRC Time to Pay is being sold as a product, it belongs here. If a court actually decides something, it belongs here — with the citation, not a thread.

You can comment. Use a display name. We will not show your email. Tick the box only if you want a mail when a new post goes up, or about a 10-minute review. Unticked means we keep a hash so you can comment again from this browser, and we do not write to you.

The courses stay quiet. No comments under *Sequana*. No likes on a lesson about personal guarantees. That is still a library.

Strata packages UK SME distress-refinance files. We do not lend. If a note here ever sounds like a facility, it has gone wrong.
